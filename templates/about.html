About the Student Management System

The Student Management System is a web-based application designed to manage student information through a simple and structured interface.

What This Application Does

The application allows authenticated users to add, view, search, edit, and delete student records. It also provides a dashboard for viewing basic student statistics.

Application Flow

The application follows a frontend-backend-database architecture:

Frontend HTML, CSS, JavaScript
↓
Backend Python + Flask
↓
Database MySQL

Authentication & Security

The application includes user registration, password hashing, login sessions, protected routes, CSRF protection, input validation, parameterized SQL queries, and environment-based configuration for sensitive values.

Technology Stack

  • Python
  • Flask
  • MySQL
  • HTML
  • CSS
  • JavaScript
  • Git & GitHub
  • Gunicorn
  • Render
  • Aiven MySQL

Project Purpose

This project was developed to understand how a frontend application communicates with a Python backend, how backend code interacts with a relational database, and how a complete web application can be tested and deployed.
